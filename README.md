🍼👶 Tienda de Disfraces para Bebés – Proyecto Final Frontend JS

Proyecto final desarrollado para el curso de Frontend JavaScript, que consiste en una tienda online de disfraces para bebés con carrito de compras, manejo de datos en JSON, interacción dinámica con DOM y uso de LocalStorage.

✨ Funcionalidades Principales

🛒 Carrito de compras dinámico (agregar, eliminar, sumar, restar cantidad).

📦 Catálogo de productos cargado desde archivos JSON.

🎯 Promociones dinámicas también obtenidas desde JSON.

💾 Persistencia con LocalStorage para mantener el carrito.

📱 Diseño responsivo en todas las páginas.

🖼️ Galería de imágenes realista de los productos.

🧭 Navegación completa entre Home, Carrito y Contacto.

✉️ Formulario de contacto validado con JavaScript.

🛠️ Tecnologías Utilizadas

HTML5

CSS3

JavaScript (ES6+)

LocalStorage

JSON

SweetAlert2
